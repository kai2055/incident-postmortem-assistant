# Personal Learning Log

This folder contains my personal notes on each incident. These are NOT part of the project build — they're my own case-study journal, where I break down complex post-mortems into simple, coherent stories and demystify unfamiliar terms.

## Purpose
- Understand what actually broke and how it was fixed.
- Build a vocabulary of infrastructure and reliability concepts.
- Connect each incident to ML reliability principles.

## Structure
Each incident gets one file: `learning/company-date.md`
